# Wildan Alfaqih — Portfolio

A personal portfolio for Wildan Maulana Akbar Alfaqih, built with React and Vite.

## Included

- Editorial, responsive portfolio layout
- Selected work from the PDF portfolio and verified project work
- Sections for approach, about, experience, and contact
- Project detail modal with private-project notices
- Copy-to-clipboard email interaction
- GitHub and LinkedIn links
- Mobile navigation

## Run locally

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
npm run preview
```

The current local `node_modules` is linked to compatible packages already installed in another project because the machine was out of free disk space during setup. Run `npm install` in this folder when disk space is available to make the dependency tree local.
